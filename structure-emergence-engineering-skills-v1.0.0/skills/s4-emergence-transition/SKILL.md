# S4：涌现与阈值变化分析

## 目的
说明局部交互如何生成整体模式，并判断观察到的变化是否足以支持“涌现”“临界转变”或“相变”这类解释。

## 触发条件
局部行为与整体结果不呈简单线性关系；存在网络效应、集体模式、反馈放大、多稳态、突变、滞后或临界点假设时。

## 输入
S1结构、S2变量/关系、S3状态转移、跨层级观测数据（若有）。

## 步骤
1. 写清微观单元及其交互规则；说明互动发生在什么网络/空间/制度环境中。
2. 找出介观结构，如社群、模块、枢纽、局部聚集或资源分配机制；若没有证据，不强行增加介观层。
3. 定义宏观模式，并挑选能追踪模式变化的候选序参量/摘要指标。
4. 明确聚合机制：局部规则通过何种路径、反馈或约束生成整体模式。
5. 区分普通非线性、阈值效应、临界转变和物理意义上的相变。除非有适当理论/数据支持，不把任何突然变化直接命名为“相变”。
6. 检查多稳态、迟滞、临界减速、规模效应、路径依赖等可检验迹象；将不适用的诊断排除并说明理由。
7. 列出至少一个替代解释，例如外部冲击、测量口径变化、样本构成改变或隐变量影响。
8. 识别可干预的局部规则、网络结构、资源流或边界条件；区分“可影响”与“可控制”。
9. 若有仿真，验证规则、参数、初始条件和随机种子，并做敏感性分析；仿真现象不能单独证明现实机制。

## 输出
微观—介观—宏观机制图、候选序参量、阈值/状态条件表、替代解释、干预点与证据缺口。

## 验收标准
- 能具体解释哪个规则通过什么机制生成何种宏观模式。
- “涌现/相变”标签有明确判据和证据等级。
- 能提出区分竞争解释的观测或实验。

## 失败判据
只写“系统复杂所以涌现”；把所有突变都称为相变；未定义序参量；忽略数据口径、外部冲击和选择偏差；用仿真输出替代现实证据。

## 工具/模板
`templates/state-transition-register.md`，并可使用专门的微观规则/宏观指标记录表。

## 信息源需求
优先检索领域综述、原始研究、数据或模型代码，并寻找未复现和不支持该机制的研究；调用S8。
