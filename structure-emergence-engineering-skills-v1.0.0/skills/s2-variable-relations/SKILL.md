# S2：变量与关系登记

## 目的
把抽象概念转化为可定义、可观测、可计算或可明确标记为暂不可测的变量与关系。

## 触发条件
需要解释差异、构建指标体系、检验机制、设计数据管道或准备状态模型时。

## 输入
S1对象与关系模型、可用数据、目标决策、测量资源与时间限制。

## 步骤
1. 从目标决策反推最小必要变量，不要把所有可想象因素全部纳入。
2. 对每个变量写明操作性定义、类型、单位/取值范围、粒度和时间频率。
3. 区分状态变量、输入/干预变量、控制参量、结果变量、观测指标、序参量、扰动/噪声。需要时另标混杂因素、中介变量和调节变量。
4. 为变量指定测量方法、数据来源、缺失值处理和测量误差风险。
5. 为每条关系标记状态：已观察关联、理论假设、实验支持、待验证，不能仅凭共变就认定因果。
6. 对因果主张画出可能的因果路径，同时指出时间顺序、混杂因素和竞争解释。
7. 标明反馈回路的方向、延迟、增益或其他可操作特征；没有数据时只作定性描述。
8. 约定数据接口：字段名、类型、单位、主键、时间戳、缺失值与更新频率。
9. 做冗余检查：两个指标高度重复时，说明为何需要同时保留。

## 输出
变量登记表、关系/因果图、观测方案、数据接口定义和关键缺口。

## 验收标准
- 每个关键变量可以被理解；已测或有明确测量方案。
- 关系陈述区分事实、推断与假设；因果主张包含替代解释。
- 数据格式和更新频率足以进入下一步分析或工程实现。

## 失败判据
变量只有名字没有定义；拿代理指标直接替代目标现象且不说明误差；把相关性写成因果；阈值没有数据或推导依据；无法说明指标为何会改变决策。

## 工具/模板
`templates/structure-variable-register.md`。

## 信息源需求
涉及统计定义、测量标准、具体数据集或外部指标时调用S8；使用自采数据时记录数据生成过程和偏差。
