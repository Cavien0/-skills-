# S7：观测与失败判据

## 目的
让关键主张可被检查、质疑和复现，确保失败可以被看见，而不是事后被解释掉。

## 触发条件
任何关键结论需要验证、MVP需要验收、系统需要监控，或分析可能受到测量偏差影响时。

## 输入
S2变量表、S3状态转移、S6测试设计、数据来源和决策后果。

## 步骤
1. 为每个关键断言指定观测指标、基线、测量频率、数据负责人和采集成本。
2. 区分领先指标、滞后指标、代理指标和最终结果；说明代理指标不能代表哪些内容。
3. 记录数据质量：缺失、延迟、定义变更、样本选择、标注误差、幸存者偏差和观测者效应。
4. 为关键主张设置反证条件、容许误差、无结论区间和停止规则。
5. 区分模型失败、测量失败、执行偏差和环境变化，避免把它们混成一个结果。
6. 建立回归测试：新版本必须与旧案例、基线或保留数据比较。
7. 需要时设置告警阈值、降级策略、人工复核和升级路径；阈值须有依据或标为初始阈值。
8. 若无法观测关键变量，说明哪些结论因此不能验证，并提出代理测量/实验/停止方案。

## 输出
指标与观测表、数据质量风险、反证/失败判据、停止规则和回归测试方案。

## 验收标准
- 每条关键主张有观测路径或明确的不可观测限制。
- 失败条件在结果出现前已写明。
- 能识别当前结果是否由数据问题、执行问题或模型问题造成。

## 失败判据
没有反证条件；只有成功指标没有停止规则；指标能被轻易操纵；不保留原始数据/版本；以不可观测为理由无限维护模型。

## 信息源需求
涉及测量标准、统计检验或行业基准时调用S8。高影响结论应说明数据限制并寻求独立复核。
